## THE BIG STATE CHANGE: RT-G IS RULED. TRACKS G AND H ARE UNBLOCKED.

**RT-G (b) — device-local history.** Ruled 2026-09-01. This is the decision that had been open
longer than any other in the project, and it is now closed:

- No accounts, no database, no recurring bill, no privacy policy, no signup wall.
- Come back in the same browser and a result can say *"your threshold moved from 31 cents to 18"*.
- Switch device or clear the browser and the history is gone — **and the product must say so
  wherever an arc is shown** (Track G2 exists for exactly this).
- The 7-day per-family retest cooldown already uses `localStorage`, so G1 is an extension of a
  mechanism that ships today, not a new dependency.

**The next session's default track is G**, then H. `ARCHITECTURE.md` has already been updated to
state the ruling and to say plainly that it is not built.

The PM's own framing when ruling it — "the most popular path for indie developers" — was answered
honestly and is worth carrying: device-local is *not* the common indie path (most reach for Supabase
or Firebase); it is the right call **here** because with n = 0 a database collects nothing while
costing a bill and a signup wall. The ruling is right for a reason specific to this project.

## FINDINGS THAT MUST NOT BE LOST

1. **A FILE JOINING A GUARDED SET IS NOT THE SAME AS A FILE BEING GUARDED.** `docs/index.html` was
   added to the published-text corpus and 18 tests went green. Reverse-tested against the *pre-fix*
   page, it **also** passed: "rate ten clips" matches no pattern, so the quantity check had nothing
   to compare and passed in silence. Per-file *required* facts are what made it bind. This is the
   most transferable finding of the session.

2. **A GUARD CAN BE BLIND BY SCOPE AS WELL AS BY NEEDLE.** `retired-gates.test.ts` — whose entire
   subject is documents that lie about their own gates — had `ROOTS = ["docs", "src", "scripts"]`
   and **never walked the repository root**, so it could not see `README.md` or `ARCHITECTURE.md`,
   the two files a stranger reads first. Its pattern also had no spelling for `ear-check`, which is
   what `ARCHITECTURE.md` called the abolished gate. Blind twice over, for a month.

3. **THREE GUARDS WERE WEAKER THAN THEIR NAMES, AND TWO WERE WRITTEN THIS SESSION.**
   - "describes no live instrument as unbuilt" **passed on the broken README**: the offending
     sentence describes the Threshold Test in full and never names it, so a needle keyed on
     `MACHINES` titles was structurally blind. Repaired by banning "in progress" outright.
   - "every live machine has an expert panel" **passed with the panel removed**, because
     `.includes("ExpertPanel")` matches `"ExpertPanelX"`. A bare identifier is a substring of every
     name built from it. Now asserts the JSX open tag `<ExpertPanel`.
   - The link-route extractor cut hrefs at `)` — markdown's terminator — and produced the path
     `/method">Method</a>` from HTML, failing a link that was fine. **A guard that cries wolf trains
     people to disable it.**

4. **A TEST'S NAME IS A CLAIM ABOUT ITS SCOPE.** After widening `retired-gates.test.ts` to the root,
   its name still read "finds none anywhere in docs, src or scripts". A name that *understates*
   scope is how a future reader concludes a file is unchecked and stops looking. Renamed.

5. **THE BACKSLASH TRANSPORT BIT AGAIN, AND FAILED SAFELY.** A scripted regex replacement had `\s`
   eaten a level; Python raised `SyntaxWarning` and the assertion failed before any write. Structure
   the script so every assertion runs **before** the single write — that is what turned a mangling
   into a no-op. Then move the edit to a literal tool with no escaping layer.

6. **QUOTING THE PRODUCT IS THE MOST BRITTLE THING A README CAN DO — SO PIN IT.** Prose about a
   feature goes vague; a quote goes *false*. Every `> ` line in the README is now asserted to be a
   substring of `vocabularyStrings()` or `expertStrings()`. Reword a template and the README fails
   by name. The quotes were deliberately chosen to be the count-free spans so they do not freeze a
   number that moves with the pool.

7. **MY OWN SWEEP PATTERN MISCOUNTED A TABLE.** `<td>[^<]*</td>` skipped the roadmap row whose label
   contains `<em>`, so "Retest arc" vanished from my results and I briefly believed a row was
   missing. Read the actual table, not the pattern's output.

8. **`refs/pull/1/head` HAS DISAPPEARED FROM THE REMOTE.** It was there on 2026-08-28, serving the
   pre-rewrite commit `e385ef9` with `sw***@***.edu`. `git ls-remote origin` now returns only `HEAD`
   and `refs/heads/main`. That is what a successful Support purge looks like — **but a disappeared
   ref is evidence, not a receipt**, and RT-L8 (a) rules that the backup refs stay until Support
   confirms in writing.
