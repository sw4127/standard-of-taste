## Findings that must not be lost

1. **The brief's starting host name was taken.** "Marrowtone" belongs to Marrowtone Smith Corp, a
   California corporation filed 2025-11-11 (and the Marrowstone Music Festival is one letter away).
   Replaced by **Tessavox**, checked alone; nine track/artist collisions were also replaced.
   Record: `docs/reading-names-check-2026-09-23.md`.
2. **The Access Now date in the brief is the press release, not the letter.** The coalition letter
   is dated 4 May 2021; Access Now published it on 19 May 2021. `/company` cites both.
3. **A guard had been vacuous since before this session.** `site-links.test.tsx` held a literal
   backspace where `/<Link\b/` was meant, so "the root layout renders no `<Link`" could never fail.
   Repaired in Part 6, with a mutation. The same Python-escape trap (`\b` → backspace) bit four
   times in this session and was caught each time by a mutation or a count of zero: **write regexes
   with the Edit tool, never through a non-raw Python string.**
4. **The snack's model had rendered a carve-out breach** ("cheaper than therapy"); no template guard
   could see model text. The site now has no model client at all, and the carve-out list covers
   therapy and clinical terms (one list, shared by the card, the site scan and the reading).
5. **Rejecting a line did not always change the prompt** in the first build (two lines shared one
   sound). Each line now contributes its own direction; a test holds it for every listener.
6. **The creation screen crashed on the first rendered run** (an expression-bodied `useEffect`
   returned `scrollTo`'s value). Fixed and guarded. No unit test saw it; only the rendered run did.
