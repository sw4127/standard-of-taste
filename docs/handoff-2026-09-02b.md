## TRACK I IS NOW SPECIFIED — BUILD IT NEXT

RT-H and RT-H2 are both ruled, so the next session can plan Track I without asking the PM anything
further about breadth. **It has not been started and no code exists.**

**Breadth means DEGREES USED (RT-H b).** Not how much music someone has heard — that would need an
import and a taxonomy we would have to invent. It is measured from the 0–10 blind ratings the
Prestige Test **already collects and already stores**: how many of the eleven scale points a person
actually used, and how many of their own pairwise judgments contradict each other. A judge with
narrow comparison compresses everything into one band and cannot assign degrees; that is Hume's
criterion, and it is a performance task where a person can be wrong (D2).

**Critics set the SPREAD, not the ANSWER (RT-H2 a).** The PM asked for outside professional
judgment — Pitchfork-style — as borrowed legitimacy. The mechanism ruled is: take works that named
critics have publicly ranked **far apart**, and works they ranked **close together**, and report how
the reader's own gaps compare to theirs. *"Critics put these two twelve points apart. You put them
one apart. On the pair they called nearly equal, you put them six apart."*

**The trap, and it is the reason this ruling is shaped the way it is:** the Prestige Test measures
being swayed by a prestigious name. **Scoring agreement with a prestigious critic would make the
product contradict itself in public.** So there is no agreement score and it never says a reader is
wrong — only that their degrees and the critics' are calibrated differently, and it names whose
ranking it used. **Any future proposal that scores agreement with critics is refused by this note.**

Also unresolved and now smaller: **RT-I's caveat** says publish FIVE sub-scores where only FOUR
exist. Either RT-H option produces a fifth, so shipping Track I closes it.
