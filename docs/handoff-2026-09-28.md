   `.githooks/pre-push`, which exports `GIT_DIR`; `test_hook_encoding.py`'s throwaway `git init`
   inherited it and re-initialised the real repository with `core.bare = true`. The background
   session found and fixed it (`2cd8506`): the hook suite drops inherited `GIT_*` variables,
   pre-push unsets them before the suite, and a decoy test reproduces it. **Any test that runs git
   in a temp directory must scrub `GIT_*`.** `record-mcp` does.

   Agent tool both answered "not found" for files created mid-session until a user prompt arrived;
   an edited agent definition likewise kept running its old version until the next message.

   (security-test removal). That is why the hook stays, labelled "measured not to deny".
