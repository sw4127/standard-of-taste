## FINDINGS THAT MUST NOT BE LOST

1. **A guard proves what its needle describes, not what its name says.** S1's sweep reported "no
   file re-implements the tint regex" — true — while four more copies existed, written with
   `slice(0, -1)` instead of a regex. The commit said "one tint" and that was false when written.
   S1's own red-team had *predicted* this hole in words and shipped anyway. **A red-team finding
   that names a specific, cheaply-checkable hole is a task, not a confession item.**

2. **The Browser pane in this environment runs HIDDEN** — `document.hidden === true`,
   `visibilityState: "hidden"`. Consequences, each of which cost real time this session:
   - `requestAnimationFrame` **never fires**, so anything rAF-driven (FluidField's cross-fade)
     cannot execute or be observed.
   - **CSS transitions never advance**, so `getComputedStyle` returns the *start* value forever.
     To read a settled value, set `element.style.transition = 'none'` first, read, then restore.
   - `computer{screenshot}` times out; nothing visual can be seen.
   This produced two nearly-shipped false findings: "the luminance system is dead" (it is not —
   `mechanismAlive: true` once the transition is disabled) and "selection changes nothing".

3. **HMR-buffered console errors persist across navigations and look exactly like live defects.**
   Three times this session a broken intermediate state left errors in the buffer that survived
   after the fix. **Always confirm in a newly created tab**, which starts with an empty buffer.

4. **Guards that match themselves — three times** (S1, S2, S8). A sweep for a string, written in a
   file that must name that string, flags itself. Two fixes used: assemble the needle from halves
   (`"replace(/" + "\\)$/"`), or put the sample in a `.txt` fixture under `__fixtures__/` that the
   `.ts`/`.tsx` sweep cannot see. **The fixture form is strictly better** — it makes the self-test
   non-circular, because the guard is proven against the real pre-fix source rather than against a
   string assembled to be found.

5. **A check satisfiable by prose is not a check.** S3's guard asserted the start handler "sets
   phase" by searching for the word `phase`; the Threshold flow satisfied it via the phrase
   "forward-only phase machine" **in a comment written in the same slice**. It had never checked
   anything. Match the setter call, not the noun.

6. **`tsc` is a separate gate from `vitest`.** 1966 tests passed green with a type error present.
   A green test run here is not a green build.

7. **The registry held a colour nothing rendered.** `PRESTIGE_GOLD_GLOW` was
   `hsl(42 85% 60% / 0.4)` and imported by **nothing**, while three files each declared
   `hsl(42 80% 60% / 0.45)`. Corrected *toward what ships*: the live copies are what has been on
   screen; the export's value was never a decision anyone made.

8. **Two whole features were dead data.** `Machine.field` — populated for every machine, documented
   as "ambient field colours while this machine is selected", read by nothing (now wired, S8).
   `FluidField.baseColor` — dead on 23 of 24 call sites, including three constants named as each
   instrument's own backdrop, describing a difference no eye has ever seen (now deleted, S7).
   **Both were found by asking what READS a value, not by reading its name and its doc comment.**
   An earlier draft of S4b asserted a visible divergence on the strength of a field's name; that
   claim was wrong and was corrected inside the same commit.

9. **The front door was shipping muted body copy at 1.99:1** against WCAG AA's 4.5, and nothing
   measured it. The neutral field is 4.67:1, chosen by measurement — the first draft was 4.07 and
   was darkened. `instrument-accents.test.ts` now measures this permanently, self-tests its meter
   against known pairs first, and requires the old gold field to still FAIL so it cannot pass
   vacuously.

10. **Scripted multi-file edits: substitution is safe, INSERTION is not.** `sed`-inserting a line
    wrote the literal `${line}` into 15 files, and an awk fix then placed an import *inside* a
    multi-line import block in two more. Whole-line exact-match substitution over ASCII was fine
    all session. Verify every scripted edit with `git show --stat` before committing.
