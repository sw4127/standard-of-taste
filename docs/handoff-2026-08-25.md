5.1 → 8.1 minutes, and the measured payoff:

| n scored | minutes | SD (pts) | verdict agreement | near-the-line agreement |
|---|---|---|---|---|
| 8 (was shipping) | 5.1 | 3.73 | 89.0% | 73.0% |
| **14 (now)** | **8.1** | **2.57** | **92.7%** | **79.9%** |

Near-the-line agreement — how often two runs of the same person land on the same verdict when they
sit close to a threshold — is the number this instrument should be judged on, and it moved 7 points.

and the fitted constant is 10.34/sqrt(n) rather than 11.02. **These figures regenerate on every test
run and vary by a few hundredths** (random subsets, 1200 simulated persons per length) — quote them
from `docs/analytics/e6-prestige.txt`, not from here.

## WHAT THE PRODUCT IS NOW

Three instruments, one gym. Free, no account on the Floor.

- **The Prestige Test** (`/bias`) — 16 clips, `BIAS_POOL_VERSION = 7`, ~8.1 min. Rate blind, rate
  again labelled. **Two** labels are deliberately false (was three). 7 up / 7 down, which makes the
  drift correction exactly zero by construction rather than by arithmetic. Reports a signed
  percentage: how far your ratings moved toward the names.
- **The Delicacy Trials** (`/delicacy`) — 18 pairs (3 practice + 15 scored), `DELICACY_POOL_VERSION = 2`,
  ~10 min. One clip of each pair is quietly damaged. Reports a **guessing-corrected band**, never a
  tier: at 12 of 15 that reads "between 10% and 86% detected", which is honest and embarrassingly
  wide, because 15 pairs is 15 pairs.
- **The Threshold Test** (`/threshold`) — an adaptive staircase, one damage family per session,
  14–26 min. Reports the **physical size** of the smallest flaw you can still hear: cents, ms, kbps.
  The deliverable of record per the D4 amendment.
- **The Lab** (`/lab`) — the analytics surface.

## MEASURED FINDINGS THAT MUST NOT BE LOST

1. **The speech gate that replaced the PM's ear-veto works for one case and not another, and says so.**
   Six features were measured against real audio; five failed, including three that came out
   *inverted* (music scoring higher than speech). Only zero-crossing-rate variance separated.
   `speechRisk > 0.90` catches an excerpt that is largely someone talking. It does **not** catch a
   short announcement over busy music, and no threshold on that feature can — 5s of credits over pb8
   reads 0.673 while clean Brahms reads 0.709. **The blind spot is a passing assertion**, so if it
   ever closes a human gets told. A second, positional gate (Musopen windows must start ≥60s in)
   correctly classifies the one case a human actually labelled. `docs/analytics/e7-speech-gate.txt`.
2. **The width model is accurate to three decimals and was under-covered.** Rendering through the
   real Satori reproduces the original browser measurement (`"48–128 kbps"` = 0.5936 against 0.593
   recorded). Six governed figures measure above 0.6, worst `"100 ms"` at 0.6183. Nothing was
   clipping — `FIT_SAFETY` was carrying it — but `"64–160 kbps"` rendered 840px against an 846px
   target, accurate by luck. `docs/analytics/e7-em-metrics.txt`.
3. **All 17 bias clips pass Layer A**, the pool's first fitness gate: duration, loudness, true peak,
   clipping, quiet fraction, dead air, speech risk, window position.
   `docs/analytics/e7-layer-a-bias.txt`. pb9 passes near-silence by one point (19.0% of 20%).
4. **The delicacy reveal's every reachable line is written out** in
   `docs/analytics/e7-delicacy-reveal.txt` — 80 sessions across five confidence patterns.
5. **Discrimination is not calibration.** Being sure exactly when you are right (95 on hits, 50 on
   misses) reads *overconfident* at a middling score, correctly: at 8/15 that averages 74%
   confidence against 53% accuracy. Pinned as its own test, because a future change that started
   rewarding ranking over accuracy would make the copy above it a false claim.
6. **archive.org's `licenseurl` field lies.** A CC0 search returns Freddie Gibbs, The Mars Volta and
   Earl Sweatshirt. Provenance — the rights-holder's own release — is the gate, never the field.

## THINGS THAT WILL BITE THE NEXT SESSION

**The recurring defect of this codebase is a guard whose scope quietly went stale.** Four instances
this session: a pathspec that missed top-level files, an artist-name comparison that skipped a
six-character name, a payment check scoped to two of three instruments, an event dictionary nineteen
behind. **Every one was green while blind.** The fix each time was a coverage assertion — a test that
the scope covers everything — never a longer list.

**Probes lie more often than the code does. Six times this session**, each confident and plausible:
a speech fixture 12 dB quieter than its label · a regex counting a docblock as a pool item · three
wrong API signatures, one of which encoded `undefined` fifteen times and passed its own assertion ·
a figure set that flagged a correct model as broken. **Measure the instrument before believing the
measurement.**

**Do not generate code through Python.** `\n` became real newlines inside JS string literals and
broke a test file. The documented rule names regex; the real rule is broader.

**Twice, the obvious fix was a trap the codebase had already documented** — naming the threshold
source, and putting the answer key on the permalink. Read the file you are about to change.
