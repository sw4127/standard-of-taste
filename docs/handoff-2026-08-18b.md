### THE UNIT MISMATCH — the thing most likely to be re-introduced
`MIN_MEASURABLE_PITCH_CENTS = 3` was measured by `rungs.mjs` in the **parameter** domain
(its table reads `param 3 -> measured 2.7`). A pitch ramp peaks at `PITCH_RAMP_PEAK_FRACTION`
(0.95) of its parameter, so **level 3.1 predicts 2.94 measured cents — below a 3-cent
*measurement* floor by construction.** The first version of the gate compared the floor to
each clip's measured p95 and flagged 8 clips that were all within 8.4% of their own
prediction.

Floors are now checked on `level`. Which makes them ladder-table properties, so **both
families carry an evidence field read from whichever `staircase-render` gate interrogates the
audio**: `levelErrVerified` (pitch's error gate) and `trajectoryVerified` (timing's trajectory
gate). Absent is an ERROR, false is a FLAG, neither is a pass. `staircasevalidate.test.ts`
carries a REGRESSION block for this.
