## FINDINGS THAT MUST NOT BE LOST

1. **A bullet in a handoff is not a queue.** Four copy batches sat as "awaiting a writing pass" from
   2026-08-26 and nothing acted on them; each handoff copied the line forward. **The one batch that
   ever completed a pass (delicacy readout, RT-107a) is the one somebody wrote a FILE for.** If work
   is to be handed to someone, produce the artefact — otherwise the record only accumulates a claim
   that something is pending.

2. **Three live false claims about a paid tier survived six weeks because the guard was looking at
   part of the room.** `voice.test.ts` had the no-paid-tier check since RT-44a and it passed, because
   the deck harvested two hand-written `learn/` strings and never `LEARN_PAGES.faq`, and never the
   `public/*.txt` files at all. **This is the fourth instance of that shape in this repo.** When you
   add a guard, assert its scope covers everything of that kind.

3. **`perl -0pi` without `-CSD` silently corrupts every multibyte character**, and nothing catches
   it: `tsc` passed, all tests passed, no mojibake pattern matched. Every em dash in `claims.ts`
   became a stray byte. Caught only by counting em-dash BYTES and hexdumping. **Use Write/Edit or
   heredocs for prose.** Sweep: `grep -oP '\xe2\x80\x94' FILE | wc -l` and `grep -c 'â' FILE`.

4. **`flat()` in `claims.test.ts` strips `*` and backticks but NOT blockquote `>`.** An anchor
   spanning a line break inside a `>` block will fail. Keep such anchors within one line. `>` was
   deliberately not stripped — it appears in arrows and comparisons.

5. **The contrast trap is real and reproduced.** The page's colours resolve to `lab(84.92 0 0)` and
   `oklab(… / 0.8)`; parsing those as RGB is what produced the historical false 1.31:1. **Convert by
   painting into a canvas and reading sRGB back.** Self-test the meter on known pairs first
   (21.00 / 21.00 / 1.00 / 4.61) before trusting a single number.

6. **`/method`'s citations failed WCAG AA and only measurement found it** — 4.37:1 at
   `text-muted/80`, on the page whose whole argument is "go and check the sources". Now 6.33:1, the
   lowest ratio on the page.

7. **A guard can go stale inside one slice.** `inference-mark.test.ts` named two rendered
   collections; the page grew a third in the same session and an inferred claim would have rendered
   unmarked with the suite green. It now derives the list from the page.
