## THINGS THAT WILL BITE THE NEXT SESSION

**My probes lied at least eight times this session.** A calibration harness mixing at −27.8 LUFS while
labelling it 0 dB · a contrast meter reading a short line as 1.35:1 and an identical long one as 4.87:1
· a swap count invented from a docblock · three wrong API guesses in a row, one of which passed its own
assertion while encoding `undefined` fifteen times · two import guards that matched JSX instead of an
import. **Measure the instrument before believing the measurement, and print the payload.**

**Guards get written against the shape you happened to see.** S20's ink guard looked for a `text-black`
class with a token on the next line; S21 found the same defect as `{ background: ICE, color: "black" }`
on one line and it sailed through. The accent guard tested `hsl(190` exactly and missed three files
whose ambient field used ice's *neighbours*.

**Do not generate code through Python.** `\n` became real newlines inside JS string literals and broke
a test file. The documented ban is on regex; the real lesson is broader. Use Write.

**Dynamic event names break the dictionary.** `` track(`bias_to_${id}_tap`) `` is now a failing test.
