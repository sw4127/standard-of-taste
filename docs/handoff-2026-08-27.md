## FINDINGS THAT MUST NOT BE LOST

1. **The within-person contrast is not measurable, and this is now settled.** The blueprint's
   headline feature ("pitch is your strength, compression your blind spot") was killed by its own
   pre-registered criterion. At 5 pairs a family, a listener with IDENTICAL true sensitivity across
   all three still shows unequal tallies **88.7–92.8%** of the time. Re-derived in
   `src/content/vocabulary/delicacy.test.ts`. **Do not re-propose it at the current pool size.**

2. **Log-spectral distance cannot be the common scale.** For pitch, the ENTIRE ladder (3.1 → 100
   cents, a 32× change) moves LSD by 1.72 dB, while swapping the recording at one rung moves it
   ~1.8 dB — the material noise exceeds the whole-ladder signal. The three families also sit in
   offset ranges (pitch 1.5–3.3, timing 3.0–5.9, lossy 1.0–12.6 dB), so any LSD ranking would tell
   EVERY listener they are sharper on pitch. Measured off `staircase.json`.

3. **What replaced it, and why it is honest.** Delicacy and the staircase measure two families in
   the SAME quantity at the SAME values — pitch 25/50/100 cents, lossy 96/64/32 kbps — read from
   `manifest.json`, never retyped. So a person who ran both was measured twice on one axis by two
   procedures, and "do the two agree?" needs no scale, cohort or norms. **Timing is excluded**:
   delicacy varies tempo by a PERCENTAGE, the staircase reports ms of drift IQR. Different
   quantities; the conversion is unmeasured.

4. **Calibration was already surfaced.** RT-D asked to promote it to a named line; the shipped page
   has had a headed `CalibrationBlock` ("DID YOU KNOW WHEN YOU KNEW?") all along. PM closed RT-D as
   already done. The blueprint is authored by something that cannot see the repo — **verify its
   premises against the code before building on them.**

5. **pb6's professional review was recorded, not missing.** `manifest.json` has said so since
   2026-07-12; `items.ts`, a DERIVED file that names that manifest as its authority, said the
   opposite for months, and the PM had to state it more than once. A derived comment inventing an
   obligation its source says is discharged. Guarded now.

## THINGS THAT WILL BITE THE NEXT SESSION

**Do not generate code through Python.** The ban is documented and I broke it twice in one slice.
`\\b` in a Python string becomes `\b` = **literal backspace 0x08**, which is invisible in grep, in
the editor and in the diff — it silently disabled the word boundaries in an N3 guard. A second
instance had already been sitting in `across.test.ts` since S8. Sweep with
`grep -rlP '\x08' src/ --include='*.ts' --include='*.tsx'` after any scripted edit. Use Write/Edit.

**A permalink mount is not a flow mount.** `AcrossSessions` was added to the three result ROUTES in
S8. `ThresholdResult` is shared with its flow so the staircase was covered by accident; the Delicacy
and Prestige flows build their own reveal markup and got nothing — so the block was live on shared
links and absent from the screens people finish on. Whenever you add to a result screen, check
**both** surfaces.

**Driving a flow in this environment (all three obstacles look like product bugs and are not):**
- `play()` is permanently blocked — no user activation is obtainable (`hasBeenActive: false` even
  after real input events), because the Browser pane is hidden and not compositing.
- `setTimeout` is throttled to roughly **1 per minute**. The trial advance in `DelicacyFlow` is a
  `setTimeout`, so a working flow looks frozen.
- `requestAnimationFrame` never fires, so the listen ring's primary banking path is dead. The code
  anticipates this and has an `ontimeupdate` backup — that is the one to drive.
- The working recipe: patch `window.Audio` to mute, seek the live element to its end and invoke the
  app's own `ontimeupdate`/`onended`, force `setTimeout` delay to 0, and yield with
  `MessageChannel` rather than `setTimeout`. Select buttons by **aria-label** — the flaw and
  confidence buttons read "The pitch drifts" and "95% — certain", not their visible text.

**Five of my diagnoses were wrong before one was right**, and each looked like a defect: a dead dev
server read as a missing panel; a driver re-clicking play every 400ms read as broken arming; a
regex matching "SCORED" inside "NOT SCORED" read as reaching the scored phase. **Measure the
instrument before believing the measurement.**
