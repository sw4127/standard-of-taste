## FINDINGS THAT MUST NOT BE LOST

1. **The within-person contrast is not measurable, and this is settled.** The blueprint's headline
   feature ("pitch is your strength, compression your blind spot") was killed by its own
   pre-registered criterion. At 5 pairs a family, a listener with IDENTICAL sensitivity across all
   three still shows unequal tallies **88.7–92.8%** of the time. Re-derived in
   `src/content/vocabulary/delicacy.test.ts`. **Do not re-propose it at the current pool size.**

2. **Log-spectral distance cannot be the common scale.** For pitch the ENTIRE ladder (3.1→100 cents,
   32×) moves LSD by 1.72 dB while swapping the recording moves it ~1.8 dB — material noise exceeds
   the whole-ladder signal. The families sit in offset ranges (pitch 1.5–3.3, timing 3.0–5.9, lossy
   1.0–12.6 dB), so an LSD ranking would tell EVERY listener they are sharper on pitch.

3. **What replaced it (RT-B).** Delicacy and the staircase measure two families in the SAME quantity
   at the SAME values — pitch 25/50/100 cents, lossy 96/64/32 kbps, read from `manifest.json`. So
   "do two independent sessions agree?" needs no scale, cohort or norms. **Timing is excluded**:
   delicacy stores a tempo FRACTION, the staircase reports ms of drift IQR.

4. **The prestige control correction is inert at the shipped pool.** 7 up-labelled and 7
   down-labelled scored items means `nUp − nDown = 0`, so RT-2a's term is identically zero for ANY
   drift. Measured across −3…+3. The mechanism succeeding, not failing. Pinned in `expert.test.ts`;
   the expert panel shows both percentages and says why they agree.

5. **Calibration was already surfaced, and pb6's review was already recorded.** Two blueprint/doc
   premises that the code contradicted. **Verify premises against the repo before building on
   them** — the blueprint is authored by something that cannot see the code, and a DERIVED file can
   invent an obligation its own source says is discharged.

## THINGS THAT WILL BITE THE NEXT SESSION

**Do not generate code through Python.** Broken twice in one slice. `\\b` in a Python string becomes
`\b` = **literal backspace 0x08**, invisible in grep, the editor and the diff — it silently disabled
word boundaries in an N3 guard, and a second instance had sat in `across.test.ts` since S8. Sweep
with `grep -rlP '\x08' src/ --include='*.ts' --include='*.tsx'`. Use Write/Edit.

**A permalink mount is not a flow mount.** `AcrossSessions` was added to the three result ROUTES;
`ThresholdResult` is shared with its flow so the staircase was covered by accident, and the Delicacy
and Prestige flows build their own reveal markup and got nothing. Whenever you add to a result
screen, check **both** surfaces.

**`share` is not `identity`.** The threshold permalink withholds `share` so it never offers a
stranger's number as your own. Keying personal panels off it made them unreachable there for
everyone. Two questions, two props.

**Never server-render the answer key.** The expert payload is derived in the BROWSER from this
device's storage. Computing it server-side would put "which pair was damaged" into the HTML of a
share target, where hiding the panel hides nothing.

**Driving a gated flow here (all three obstacles look like product bugs and are not):**
- `play()` is permanently blocked — no user activation obtainable, pane hidden and not compositing.
- `setTimeout` is throttled to ~1/minute; `DelicacyFlow`'s trial advance is a `setTimeout`, so a
  working flow looks frozen.
- `requestAnimationFrame` never fires; the listen ring's `ontimeupdate` backup is the path to drive.
- Recipe: patch `window.Audio` to mute, seek the live element to its end and invoke the app's own
  `ontimeupdate`/`onended`, force `setTimeout` delay to 0, yield with `MessageChannel`. Select
  buttons by **aria-label** — flaw/confidence read "The pitch drifts", "95% — certain".

**Fixtures alias onto pool structure.** `MEASURED_TRIALS` is a strict pitch/timing/lossy 3-cycle, so
`i % 3` put every wrong answer on one family and a "mixed" session was degenerate. Assert fixtures
are non-degenerate.

**Five of my diagnoses were wrong before one was right**, each looking like a defect: a dead dev
server read as a missing panel; a driver re-clicking play read as broken arming; a regex matching
"SCORED" inside "NOT SCORED" read as reaching the scored phase. **Measure the instrument first.**
