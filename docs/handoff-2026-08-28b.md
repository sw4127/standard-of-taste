### The approach that worked, and the one to reuse: STAGED PUSHES

A single 200 MiB push did not survive this link, and each failure cost the whole upload. Pushing
the history in chunks fixed it: once the first chunk lands, the remote and local share history, so
git's negotiation works and every later chunk sends only what is genuinely new. Chunk sizes dropped
from 200 MiB to roughly 1000 objects each, and each success is durable.

**It is safe to interrupt. Every commit on local `main` is PII-clean** (all 340 verified), so a
partially-pushed public repo is still remediated — merely incomplete.

The first chunk must carry the lease check; the rest are fast-forwards:

```
git -c credential.helper='!gh auth git-credential' -c http.postBuffer=734003200     -c http.version=HTTP/1.1     push --force-with-lease=main:ab68c178cef17c0db0cd3d1edf0f8a6f579def9b --progress     origin 4b8dc67711b4:refs/heads/main

# then, in order, each a plain fast-forward:
#   ae785594b8bd  297f31358112  6c3798cc1e78  7220b617c337  and finally main
git -c credential.helper='!gh auth git-credential' -c http.postBuffer=734003200     -c http.version=HTTP/1.1 push --progress origin <sha>:refs/heads/main
```

Checkpoints are commits 40 / 100 / 170 / 240 / 300 of 340, oldest-first
(`git rev-list --reverse main`). Regenerate them if the history moves.

**NEVER PIPE A PUSH INTO `tail` OR `head`.** That is how attempt 3 came back green while the remote
was untouched. Read the log file, and verify with `git ls-remote` — the remote is the only fact.

### ⚠ BUT THE DELETED BRANCH'S COMMIT IS STILL SERVED, AS A PULL-REQUEST REF

`git ls-remote origin` now returns:

```
4b8dc677…  HEAD
4b8dc677…  refs/heads/main
e385ef9…   refs/pull/1/head     <-- the pre-rewrite commit, still reachable
```

**Deleting a branch does not delete the pull request opened from it.** GitHub keeps `refs/pull/N/head`
for the life of the PR, it is fetchable by anyone, and a normal push cannot delete it — the ref is
owned by the PR, not by the branch. So the addresses in `e385ef9` remain publicly reachable even
though the branch is gone.

This was **not** in the original plan and nobody had noticed the PR existed.
