The four places that named a fourth degradation family, exactly as they stood at
commit d740cde, immediately before E11/S1 (Track B).

There are three families. `DEGRADATION_FAMILIES` in src/engine/delicacy.ts has held
exactly ["pitch-drift", "timing-smear", "lossy-artifact"] for the life of the pool,
and the clip pipeline has never rendered a fourth. Two of the four sites below were
LIVE pages: the delicacy explainer's body paragraph, and a reading-room FAQ answer
that is also served as FAQPage JSON-LD, so search engines were told it as well.

This is a .txt on purpose. The guard in `flaw-families.test.ts` sweeps every `.ts`
and `.tsx` file under `src/` for the phrase below and allows NO exceptions — an
exception list is exactly how the third copy of `tint` survived E10/S1. So the
sample the guard is tested against cannot live in a source file. It lives here, and
the test reads it, which makes the self-test non-circular: the guard is proven
against the real defect as it really was, not against a string the test assembled in
order to find it.

The fourth site was a code comment saying the pitch ladder produces a drift and NOT
this thing. It was true, and it was rewritten anyway, because keeping it would have
forced the sweep to carry an exception — and the exception, not the phrase, is the
part that has historically done the damage.
